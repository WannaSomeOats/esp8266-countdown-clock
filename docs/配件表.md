## 五、明确「不要」的东西

| 元件 | 原因 |
| --- | --- |
| 消抖电容（100nF） | **按决定不装**，靠软件消抖 20~50 ms，完全够用 |
| 外部上拉电阻 | 用 `pinMode(pin, INPUT_PULLUP)` 内部上拉 |
| 电解电容 | 有极性、容量大，是电源滤波用的，本项目用不到 |
| 安规电容（X2 / Y2） | 市电 EMI 滤波用，和 3.3V 直流电路完全不相关 |

## 六、接线总览

| 外设 | 信号 | GPIO | 开发板丝印 | 备注 |
| --- | --- | --- | --- | --- |
| AHT30 + PCF8563 | SDA | **GPIO4** | D2 | 共用一条 I2C 总线 |
| AHT30 + PCF8563 | SCL | **GPIO5** | D1 | 共用 |
| ST7735 | SCK | **GPIO14** | D5 | 硬件 SPI |
| ST7735 | MOSI（模块丝印 SDA） | **GPIO13** | D7 | 硬件 SPI |
| ST7735 | CS | **GPIO15** | D8 | |
| ST7735 | DC | **GPIO0** | D3 | |
| ST7735 | RES | **GPIO16** | D0 | |
| ST7735 | BLK（背光） | **3.3V** | — | 不占 GPIO |
| 按键 A | 一端接 GPIO，一端接 GND | **GPIO2** | D4 | 用内部上拉，按下读低 |
| 按键 B | 一端接 GPIO，一端接 GND | **GPIO12** | D6 | 同上 |

**共占用 7 个 GPIO**（GPIO0、4、5、13、14、15、16）；按键再占 2 个（GPIO2、GPIO12）。
11 个可用 GPIO 里**只剩 GPIO1（TX）和 GPIO3（RX）**，这两个是串口脚，会与板载 USB 转串口芯片冲突，只适合当应急备用（日常靠 OTA 无线烧录）。

> **I2C 上拉说明**：AHT30 模块和 PCF8563 模块通常各自板载 4.7k 上拉电阻，并联后约 2.35k，在 3.3V 下仍然完全可用，**不需要额外处理**。

## 七、采购建议（分三阶段）

### 阶段 1 · 先点亮屏（最小系统）
**开发板 + ST7735 + 杜邦线**
→ 就能跑 TFT_eSPI 的示例程序，先确认屏能亮、驱动 IC 认对

### 阶段 2 · 加传感器和 RTC
**AHT30 + PCF8563 + CR2032 + 杜邦线**
→ 跑通 I2C 扫描（应该能看到 `0x38` 和 `0x51` 两个地址）、读温湿度、读写时间

### 阶段 3 · 焊洞洞板
**轻触开关 ×2 + 洞洞板 + 单芯线 + 排针**
→ 全部功能在面包板/杜邦线上验证通过后，再焊到洞洞板上定格

> 之所以分阶段：焊接是**不可逆**的一步。先用杜邦线把代码和接线都调通，焊板时才不会因为"到底是代码问题还是焊接问题"来回折腾。

## 八、下单/焊接前还要实测确认的事

| # | 要确认什么 | 怎么测 | 影响 |
| --- | --- | --- | --- |
| 1 | 屏是 TN 还是 IPS | 详情页标称 **IPS 全视角**，建议按文末附录的方法复核一次 | 若实测是 TN，才需要考虑换屏 |
| 2 | 屏模块 CS 脚有没有上拉电阻 | 万用表量 CS 到 VCC 的阻值 | 若有上拉，GPIO15 上电被拉高会**无法启动**，需把 CS 改到 GPIO12 |
| 3 | 开发板 GPIO0（D3）是否带 FLASH 按键 / 电容 | 肉眼 + 万用表 | 有 100nF 电容会拖慢 DC 翻转导致屏出花 |
| 4 | 四脚开关哪两个脚"按下才导通" | 万用表蜂鸣档 | 接错同侧两脚 = 短路，按键失效 |
| 5 | 按键高度选 5 mm 还是 7 mm | 取决于壳体面板到 PCB 的距离 | 影响外壳开孔设计 |

## 附录 · 复核屏幕是 IPS 还是 TN

### 详情页标称怎么看

| 详情页写的 | 解读 |
| --- | --- |
| 彩屏 / **65K 全彩** | **65K = 65,536 = 2¹⁶**，即 RGB565 16 位色 —— 与 ST7735S 走 SPI 时的实际色深**完全吻合**，参数自洽 ✅ |
| **IPS 全视角** | 若属实，就不需要换屏，这是最理想的结果 |
| 驱动 IC = ST7735 | 与 TFT_eSPI 库对得上 ✅ |

> 电商文案里的 "IPS 全视角" 有时会被宽松使用（部分 TN 加广视角偏光片也会这么标），花 1 分钟复核一下最稳。

### 复核方法：8 级灰阶条 + 斜视

1. 点亮屏后让屏幕铺满 8 条**从黑到白**的灰阶横条
2. **正视**一次，记住顺序（左黑右白）
3. 从**屏幕正上方俯视**，再从左 / 右 **60° 斜视**
4. 判断：

| 现象 | 结论 |
| --- | --- |
| 灰阶顺序**不变**，只是整体变暗 | **IPS** ✅ 不用换屏 |
| 灰阶顺序**颠倒 / 塌陷**（亮的变暗、暗的变亮） | **TN** ⚠️ 考虑换 IPS 版 |

> TN 最典型的特征是**灰阶反转**，比"左右看发白"更明显、更可靠，是首选判据。

### 测试代码（阶段 1 点亮屏时顺手跑）

```cpp
#include <TFT_eSPI.h>
TFT_eSPI tft = TFT_eSPI();

void setup() {
  tft.init();
  tft.setRotation(0);                    // 竖屏 128×160
  for (int i = 0; i < 8; i++) {
    uint8_t g = i * 36;                  // 0, 36, 72 ... 252
    tft.fillRect(0, i * 20, 128, 20, tft.color565(g, g, g));
  }
}
void loop() {}
```
