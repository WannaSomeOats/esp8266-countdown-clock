# 双层 ESP8266 倒数日 — Ver0.1 引脚分配表（硬件已确认）

> 主控：ESP8266MOD 开发板 ｜ 传感器：AHT30 ｜ RTC：PCF8563 ｜ 屏：1.8" ST7735 SPI（8 针）

---

## 一、硬件确认

| 项目 | 内容 | 对引脚预算的影响 |
| --- | --- | --- |
| 主控 | 顶盖丝印 **ESP8266MOD** 的开发板 | 即 AI-Thinker ESP-12F / ESP-12S 系列模块，可用 GPIO 与 ESP-12F **完全一致 = 11 个**，无需纠结 12E/12F（ESP-12E 与 ESP-12F 的可用 GPIO 本来就相同） |
| AHT30 | I2C，地址 0x38 | 2 脚，可与 RTC 共用总线 |
| PCF8563 | I2C，地址 0x51；**选 PCF8563T（SOP-8）** | **0 脚**（共用 I2C 总线），地址与 AHT30 不冲突 ✅ |
| ST7735 屏 | 8 针 SPI：VCC / GND / SCL / SDA / RES / DC / CS / BLK | 5 脚（BLK 不控则 0 脚） |

> ESP8266 可用 GPIO 共 11 个：GPIO0、1、2、3、4、5、12、13、14、15、16。
> GPIO6 ~ GPIO11 内部接 SPI Flash，绝对不可用；A0 是 ADC，不算 GPIO。

> **RTC 封装必须认准**：PCF8563 是**基础型号**，后缀才决定封装 —— 四者功能、寄存器、I2C 地址（0x51）、电气参数**完全一致**，只有封装不同：
>
> | 订货型号 | 封装 | 引脚间距 | 手焊难度 |
> | --- | --- | --- | --- |
> | **PCF8563T** | **SOP-8**（本体 3.9 mm） | **1.27 mm** | ✅ 最容易，**本项目选它** |
> | PCF8563TS | TSSOP-8（本体 3.0 mm） | 0.65 mm | ❌ 难，且**焊盘与 SOP-8 不通用** |
> | PCF8563P | DIP-8 直插（300 mil） | 2.54 mm | 好焊，但 PCB 要打孔 |
> | PCF8563BS | HVSON10 无引脚 | 底部焊盘 | ❌ 手工不可行 |
>
> **订货优先选 `/5` 版本**（如 `PCF8563T/5`）：`/4` 是旧版本，NXP 已标注 "Not recommended for new designs"。丝印只是短码（如 `8563T`/`PCF8563`/`P8563`），**靠丝印分不清封装，量引脚间距才准**。

## 二、定稿引脚分配

| 功能 | GPIO | 开发板丝印 | 说明 |
| --- | --- | --- | --- |
| I2C SDA | **GPIO4** | D2 | AHT30 + PCF8563 共用，外部 4.7k 上拉 |
| I2C SCL | **GPIO5** | D1 | 同上 |
| 屏 SCK | **GPIO14** | D5 | 硬件 SPI 时钟 |
| 屏 SDA(MOSI) | **GPIO13** | D7 | 硬件 SPI 数据 |
| 屏 CS | **GPIO15** | D8 | 利用它"上电必须为低"的特性匹配 CS 空闲态 —— 但**有一个前提，见第五节** |
| 屏 DC | **GPIO0** | D3 | 上电被板载上拉为高，满足启动要求 |
| 屏 RES | **GPIO16** | D0 | 无中断需求，是最适合做复位输出的脚 |
| 屏 BLK | **3.3V**（推荐） | — | 浮动即点亮；若要用 GPIO 控制则需另占一脚 |

**占用：7 脚（BLK 直连 3.3V）／8 脚（BLK 用 GPIO 控制）。**

## 二·B、变体方案：屏 RES 接到 EN，省出 GPIO16

**结论：可以，能实打实空出 1 个 GPIO（GPIO16）。** 但空出来的是 11 个脚里最弱的一个，值不值得看用途。

### 怎么接

1. 把屏模块的 **RES 引脚**飞线接到开发板上的 **RST** 或 **EN** 排针。
   - 接 **RST**（推荐）：按复位键时屏幕跟着一起复位
   - 接 **EN**：EN 运行期间必须为高，效果等价。区别在于有的板子按复位键不会拉低 EN，屏幕不跟着复位 —— 但下面第 2 点能兜住
   - 两者在"上电时由低到高"这一点上一致，都能给屏一个有效复位

2. **前提条件：初始化序列必须以软复位指令开头。**
   ST7735 的 `SWRESET = 0x01`，标准初始化流程：
   ```
   0x01 (SWRESET) → 延时 120ms
   0x11 (SLPOUT)  → 延时 120ms
   ... 其余初始化命令
   ```
   只要 `0x01` 在里面，硬件 RES 就**只需要在冷启动那一次**起作用，之后完全用不上。

3. **软件侧改一行**：TFT_eSPI 里把 `#define TFT_RST -1`（官方注释原话就是 "Set TFT_RST to -1 if display RESET is connected to ESP RST or EN"）。其他库同理，传 `-1` 表示不由 GPIO 控制复位。

### ⚠️ 空出来的是 GPIO16 —— 全芯片最弱的一个脚

| ✅ 能做 | ❌ 不能做 |
| --- | --- |
| 数字输出 `digitalWrite` | **没有内部上拉**（只有 `INPUT_PULLDOWN_16`），做按键必须外接 10k |
| 数字输入 `digitalRead`（**只能轮询**） | **没有外部中断**，不能做唤醒源 |
| 深度睡眠唤醒（接 RST） | **没有硬件 PWM**，`analogWrite` 无效 |
| 输入下拉 `INPUT_PULLDOWN_16` | 不能复用 I²C / SPI / UART |

### 值不值得？看你想拿它干什么

| 你想接的东西 | GPIO16 行不行 |
| --- | --- |
| **有源蜂鸣器**（番茄钟报时） | ✅ **非常合适** —— 纯数字输出，GPIO16 的短板一个都不涉及 |
| 第 5 个按键 | ✅ 可以，但要外接 10k 上拉 + 只能轮询，没有中断手感偏钝 |
| 光敏 / 热敏的数字输出模块 | ✅ 可以，同样要外接上拉 |
| **无源蜂鸣器**（要 PWM 出不同音调） | ❌ 不行，没有 PWM |
| **背光 PWM 调光** | ❌ 不行，没有 PWM，得改用 GPIO12 |

### 引脚账本对比

| | I2C | 屏 SPI | 屏 RES | 剩余可用 |
| --- | --- | --- | --- | --- |
| **现状** | GPIO4 / 5 | 14 / 13 / 15 / 0 | GPIO16 | GPIO1、2、3、12（4 个） |
| **RES 接 EN 后** | GPIO4 / 5 | 14 / 13 / 15 / 0 | **不占 GPIO** | GPIO1、2、3、**12、16**（5 个） |

### 判断

**GPIO16 用来做屏的 RES 本来就是一次很合理的分配** —— RES 是"上电拉一下就再也不管"的纯输出，正好匹配 GPIO16 "没中断、没上拉、没 PWM"的短板，属于把最弱的脚用在了要求最低的活上。

只在两种情况才值得把它换出来：

- 要加**有源蜂鸣器**（番茄钟必须有声音提醒）→ 值得换，这是 GPIO16 最合适的替代用途
- 确实需要**第 5 个按键** → 可以换，但要接受外接上拉 + 轮询

如果你想做的是**背光 PWM 调光**，那别指望 GPIO16 —— 它做不到，得改用 GPIO12。

## 三、按键数量结论（直接回答）

11 脚 − 7 脚 = **剩 4 脚**；若 BLK 也用 GPIO 控制，**剩 3 脚**。

| 情形 | 可加按键 | 代价 |
| --- | --- | --- |
| BLK 直连 3.3V + 放弃串口 | **4 个**（GPIO1 / GPIO2 / GPIO3 / GPIO12） | 失去 UART0，串口调试与串口烧录都没了 |
| BLK 用 GPIO 控制 + 放弃串口 | **3 个**（GPIO1 / GPIO2 / GPIO3） | 同上 |
| **保留串口调试**（推荐） | **2 个**（GPIO2 / GPIO12）；BLK 若也控制则只剩 **1 个** | 无 |

### 关键限制：GPIO1 / GPIO3 别轻易用

你这块是**现成的开发板**，GPIO1(TX) / GPIO3(RX) **同时还接在板载 USB 转串口芯片上**。拿它们接按键会出现：

- 按键的上拉/下拉与 USB 芯片输出**互相打架**（GPIO3 是 USB 芯片在驱动，按下等于把它的输出短路到地）
- 烧录时必须拔掉或断开按键，非常别扭

所以实践上把这两个脚当成**应急备用**，日常改用 **OTA 无线烧录**（ESP8266 原生支持）。

### GPIO2 的接线要求（唯一有讲究的一脚）

GPIO2 上电必须为高 → 按键必须是「**外部 10k 上拉 + 按下接地**」的接法，并且**上电瞬间不要按住它**。
（代码里用 `pinMode(2, INPUT_PULLUP)` 内部上拉也可以。）

## 四、还能再挤出按键的三种办法

1. **A0 电阻分压梯（最划算）**
   A0 完全空闲，一个脚挂 3~4 个按键（各串不同阻值电阻），用 `analogRead` 读电压判键。
   - ⚠️ 你的开发板若已把 A0 分压到 0~3.3V，可直接按 3.3V 设计；若是裸模块则 A0 只有 **0~1.0V** 量程。
   - 缺点：多键同按会误判，只能单键判定。

2. **把屏 RES 从 GPIO16 改接到 ESP8266 的 EN**
   ST7735 支持软复位指令（`0x01`），硬件 RES 跟着主控一起复位完全够用 → **腾出 GPIO16** 做第 5 个按键。
   - ⚠️ GPIO16 **无内部上拉、无中断支持**，必须外接 10k 上拉，只能轮询读，不能做中断唤醒。

3. **用 PCF8563 的 /INT 脚**
   可当作定时中断源（例如每天 0 点唤醒刷新天数），但要占 1 个脚（净增 0）。

## 五、接线前必须实测确认的 3 个点

1. **屏模块的 CS 脚上有没有上拉电阻？**
   万用表量 CS 到 VCC 的阻值。若有上拉 → GPIO15 上电被拉高 = **无法启动**。
   这种情况把 CS 改到 GPIO12，可用按键数随之减 1。

2. **开发板的 GPIO0（D3）上有没有 FLASH 按键和 100nF 电容？**
   有电容会拖慢 DC 翻转，屏可能出花；有按键则误按会切换 DC。
   若有，把 DC 挪到 GPIO2、GPIO0 让出来（但 GPIO0 作为按键同样有上电限制）。

3. **BLK 是不是真的"浮动=亮、拉低=灭"？**
   若是，程序里 `pinMode(BLK, INPUT)` = 亮、`pinMode(BLK, OUTPUT) + digitalWrite(LOW)` = 灭，**不需要任何额外元件**。
   但要 PWM 调光的话需要外加上拉电阻。

## 六、推荐落地配置（倒数日 · 3 键 · 零牺牲）

| 按键 | 引脚 | 功能 |
| --- | --- | --- |
| 1 | GPIO2（D4） | 模式 / 设置 |
| 2 | GPIO12（D6） | ＋ |
| 3 | A0 | －（单键判读） |

→ **串口保留、BLK 直连 3.3V、屏的 5 脚一个不动。**

**进阶替代（体验更好）**：改用 **EC11 旋转编码器** —— A/B 相接 GPIO2 + GPIO12 实现"旋转选值"，按下确认键接 A0。
倒数日调日期时"转"比"两个加减键"顺手得多。

## 七、按键器件：6×6 轻触开关

**可行，而且这就是标准选择。** 先分清三种开关，选错就白焊：

| 类型 | 行为 | 能不能用 |
| --- | --- | --- |
| **轻触开关**（momentary / 瞬时） | 按下导通，松手断开 | ✅ 就是它 |
| 自锁开关 | 按一下锁住，再按弹开 | ❌ 不能用，做不了短按/长按 |
| 拨动 / 钮子开关 | 保持状态 | ❌ 不能用 |

### 2 脚还是 4 脚？

| | 2 脚 | **4 脚（推荐）** |
| --- | --- | --- |
| 焊点 | 2 个 | 4 个 |
| 机械强度 | 一般，反复按压的力全压在 2 个焊盘上 | 好，4 点固定，抗按压扭矩 |
| 价格 / 常见度 | 略贵、选择少 | 最便宜最通用 |

**建议选 6×6 四脚** —— 电气上它仍然是"两端"的器件，四脚只是机械固定更好。
四脚的正确取脚方式：**同一侧的两个脚内部本来就连通，必须跨侧取脚（对角最保险）**。
拿不准就用万用表蜂鸣档量一下"按下才导通"的那两个脚。

### 选型参数

- **力度：160gf**（比 250gf 轻，长期频繁按不累；倒数日的设置键会经常用）
- **高度**：5mm / 6mm / 7mm，按"壳体面板到 PCB 的距离"来选，也可以配 6×6 专用按键帽
- **寿命**：一般 10 万次以上，完全够用

### 接法（以 GPIO2 为例）

```
3V3 ──[10k]──┬────── GPIO2 (D4)
             │
        ┌────┴────┐
        │  开关   │   ← 100nF 并联在此（可选，硬件消抖）
        └────┬────┘
            GND
```

- 开关一端 → GPIO（如 D4），另一端 → GND
- GPIO2 用**上拉**（`pinMode(2, INPUT_PULLUP)` 或外部 10k），按下读到低电平
- **建议并联 100nF 做硬件消抖**（引脚对 GND），但**软件消抖 20~50ms 仍然必须做**，两者不互替
- ⚠️ **上电瞬间不要按住 GPIO2 上的键** —— GPIO2 上电必须为高，按住会让启动失败

### 配套元件（洞洞板直插焊接）

| 元件 | 规格 | 说明 |
| --- | --- | --- |
| 消抖电容 | **100nF 瓷片电容（标称代码 `104`）**，耐压 50V，**脚距 5.08mm** | 跨在开关两端，无极性，随便哪个方向焊 |
| 上拉电阻 | **10k，1/4W 直插** | 见下面的"电容与上拉的配合" |

**不要用**：
- **电解电容** —— 有极性、容量大（µF~mF 级），是电源滤波用的，这里没有意义
- **安规电容（X2 / Y2 类）** —— 用于市电 EMI 滤波，耐压几百伏、体积大、贵，和这个场景**完全不相关**

### ⚠️ 电容与上拉的配合（容易忽略）

ESP8266 的**内部上拉很弱**（约 30~50kΩ）。如果只用内部上拉却挂 100nF：
`RC ≈ 40k × 100nF = 4ms` —— 这会让 **GPIO2 上电时电压上升太慢**，而 GPIO2 上电必须为高，存在启动失败的风险。

两种正确组合，任选其一：

| 方案 | 元件 | RC 时间常数 | 评价 |
| --- | --- | --- | --- |
| **A（推荐）** | 100nF + **外部 10k 上拉** | ≈ 1ms | 和 NodeMCU 官方电路一致，最稳 |
| B（省一个电阻） | **10nF（`103`）** + 只用内部上拉 | ≈ 0.4ms | 也能用，滤波效果弱一些 |

> 洞洞板上元件不多，建议直接选方案 A —— 多一个 10k 电阻，换来的是确定不会出启动问题。
>
> 另外：**这个电容本身是可选的**，软件消抖 20~50ms 已经能对付轻触开关。加了它能减少软件误判，属于锦上添花。
